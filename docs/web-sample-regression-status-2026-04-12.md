## 当前已补强的兼容点

- `dependency` 壳工程的 `preset` 读取改为 project 根级 `preset`，不再误读 `general.properties`
- `display condition` 已支持：
  - `&&`
  - `||`
  - 括号
  - `== / === / != / !== / > / >= / < / <=`
  - 布尔裸值
  - `.value` 形式引用
- 对带三元表达式或赋值副作用的 condition 采取 fail-open，优先避免原生属性 UI 被误隐藏
- `general.localization.{lang}` 结构已支持按系统语言和英文回退
- `color` 属性已支持：
  - Wallpaper Engine RGB 字符串
  - `#rgb`
  - `#rrggbb`
  - `#rrggbbaa`（忽略 alpha）
  - `rgb(...)`
  - `rgba(...)`
  - `255,255,255` / `255 255 255`
- Web 诊断报告会额外给出外部资源/服务依赖摘要，避免把网络/第三方失败误看成宿主入口损坏

---

## 当前仍需继续验证的边界

- `display condition` 中的副作用表达式目前是“放行但不执行副作用”，需继续观察是否会影响个别 mega-config 样本的说明文本联动
- `file` 与 `directory` 目前已做前置条件识别，但仍需样本级复查 `ondemand` / `fetchall` 的实际页面行为
- `shader / canvas / WebGL` 类样本的最终兼容仍不能只靠静态扫描，需结合运行态验证
- 含天气、NASA、外部 API 的样本仍可能出现“页面可启动但部分功能失效”，应单独归档为外部依赖问题而不是宿主损坏
- `884307090` 类旧音频可视化样本当前已基本恢复，但“频谱体感”仍属于可继续细调项，不应再与“波形不更新 / listener 断链”混为一谈
