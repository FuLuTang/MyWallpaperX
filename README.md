# MyWallpaperX

MyWallpaperX 是一款 macOS 动态壁纸应用，支持本地视频壁纸、图片素材管理、在线壁纸浏览下载，以及 Steam 创意工坊资源下载与播放。

## 功能

- 本地视频壁纸库：导入、管理、搜索视频，并设置为桌面动态壁纸。
- 特别喜爱与最近使用：快速找到常用或最近播放过的壁纸。
- 标签管理：给视频壁纸分类，方便按标签整理和查找。
- 图片壁纸库：导入、浏览和管理本地图片素材。
- Pixabay 在线库：浏览在线壁纸资源，下载后可设为壁纸。
- Steam 创意工坊：浏览、下载和管理创意工坊壁纸资源，支持视频和web类型壁纸。
- 本地预览与文件管理：支持查看详情、QuickLook 预览、在访达中显示文件等常用操作。
- 菜单栏与窗口操作：提供 macOS 风格的侧边栏、工具栏、菜单和状态栏体验。
